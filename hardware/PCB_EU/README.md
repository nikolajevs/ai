## Проверки

Проверено **KiCad CLI 10.0.7**: ERC 0 ошибок/0 предупреждений; 51 проверка, 479 подключённых выводов. Исключений ERC в проекте нет; сохранены четыре стандартные отключённые категории KiCad, перечисленные в `validation.json`.

Для реального PCB: 22 175 проверок размещения; DRC со сверкой схемы — 0 геометрических нарушений, 0 расхождений и **355 неразведённых соединений**. PCB пересобран из `placement.json` и netlist через `build_board.py` + `route_power.py`; та же процедура на прежних данных даёт файл, побайтово совпадающий с прежним PCB. Отдельно проверены 49 объектов меди и восемь физически связанных групп LED1. Проверены обе стороны, нумерация/цепи площадок, THT-маска, courtyards, запас вокруг паек на противоположной стороне, RF и предварительные механические резервы. Это проверка частичной разводки: контроллер LED1, Kelvin-цепи и остальная плата ещё не закончены. Крепёж радиаторов, толщины меди, допустимые токи, температура и поведение преобразователя пока не подтверждены.

Целевая версия репозитория по `AGENTS.md` — **10.0.6**. Она здесь отсутствует; на этой версии результат пока не подтверждён. Обычная команда `hardware/check_all.py` ориентирована на старую PCB_V1 и в здешнем окружении остановилась из-за отсутствия `/usr/bin/kicad-cli`; лог — `review/baseline_check_all.txt`. Её успешное выполнение не заявляется.

Повторить проверки новой схемы с установленным KiCad 10.0.6:

```sh
python3 hardware/PCB_EU/tools/run_checks.py
```

Другую локальную версию разрешать явно, с записью фактической версии в результат:

```sh
python3 hardware/PCB_EU/tools/run_checks.py --kicad-cli /path/to/kicad-cli --allow-other-version
```

Схемы воспроизводятся без сторонних Python-пакетов:

```sh
python3 hardware/PCB_EU/tools/generate.py
```

Специальные посадки воспроизводятся командой `python3 hardware/PCB_EU/tools/generate_footprints.py`. Дополнительный DRC библиотечных образцов: `python3 hardware/PCB_EU/tools/check_footprint_drc.py --kicad-cli /path/to/kicad-cli`; нужен `pcbnew` той же версии в выбранном Python. Этот DRC не проверяет PCB изделия.

Проверка PCB требует Python с `pcbnew` той же версии; при необходимости указать `--kicad-python /path/to/python` или `KICAD_PYTHON`. `tools/build_board.py` воспроизводит неразведённый PCB из `placement.json` и экспортированного netlist, отказывается затирать дорожки/переходные/заливки. Для воспроизведения скопировать `PCB_EU.kicad_pro` во временный каталог с тем же базовым именем, использовать `--output /temporary/PCB_EU.kicad_pcb`, затем `tools/route_power.py --board /temporary/PCB_EU.kicad_pcb`. Последний добавляет план `routing.json`, сохраняет прочую медь и отказывается менять уже существующий объект с тем же UUID, если его геометрия отличается. Для DRC временной копии нужны проект и локальные библиотеки. Перед ручным изменением размещения сохранить координаты в JSON. `tools/plot_board.py --kicad-cli /path/to/kicad-cli` обновляет оба обзора (нужны PyMuPDF и Pillow).

Генератор схем перезаписывает схемы: после ручного редактирования сначала перенести изменения в генератор. ERC, связность и геометрический DRC не подтверждают устойчивость преобразователей, температуру, фактическую сборку с радиаторами или поведение прототипа.
