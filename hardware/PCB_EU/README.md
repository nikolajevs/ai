# GrowBox — новая плата с европейской закупкой

**EU-0.1, 20.10.2026: черновик электрической схемы.** Открыть [PCB_EU.kicad_pro](PCB_EU.kicad_pro) в KiCad 10. Проект содержит корневой лист и восемь функциональных листов, 188 покупных электрических элементов и восемь площадок для измерений. Контур, размещение и разводка ещё не созданы.

Сохраняются функции PCB_V1: два LED-канала с общей яркостью, два независимых PWM/тахоканала вентиляторов, PTC, помпа, SHT4x, поплавок, RTC с CR2032, microSD, Wi-Fi и существующие функции интерфейса/расписаний. Функциональное основание — `origin/main` `1d6b1eaf1273149b32eb1cf5c91fc69ff6a6ca09`.

**Старую прошивку на эту плату не устанавливать:** GPIO и микросхема RTC изменены. Например, прежний GPIO25 помпы теперь управляет LED. Новая прошивка пока не написана и не собрана.

## Проверки

Проверено **KiCad CLI 10.0.7**: ERC 0 ошибок/0 предупреждений; 49 проверок, 488 подключённых выводов. Повреждённая копия с объединёнными выходами TC4427 была отдельно отвергнута ERC (`pin_to_pin`): проверка конфликтов выходов работает. Исключений ERC в проекте нет; сохранены четыре стандартные отключённые категории KiCad, перечисленные в `validation.json`.

Целевая версия репозитория по `AGENTS.md` — **10.0.6**. Она здесь отсутствует; на этой версии результат пока не подтверждён. Обычная команда `hardware/check_all.py` ориентирована на старую PCB_V1 и в здешнем окружении остановилась из-за отсутствия `/usr/bin/kicad-cli`; лог — `review/baseline_check_all.txt`. Её успешное выполнение не заявляется.

Повторить проверки новой схемы с установленным KiCad 10.0.6:

```sh
python3 hardware/PCB_EU/tools/run_checks.py
```

Другую локальную версию разрешать явно, с записью фактической версии в результат:

```sh
python3 hardware/PCB_EU/tools/run_checks.py --kicad-cli /path/to/kicad-cli --allow-other-version
```

Схемы воспроизводятся без сторонних Python-пакетов:

```sh
python3 hardware/PCB_EU/tools/generate.py
```

Генератор перезаписывает схемы: после ручного редактирования в KiCad сначала перенести изменения в генератор. ERC и проверка связности не подтверждают устойчивость преобразователей, температуру, посадочные места, габарит 100×100 или поведение реального прототипа.

Источники и полный статус — в [DESIGN.md](DESIGN.md) и [libraries/SOURCES.md](libraries/SOURCES.md).
