# GrowBox — контроллер гроубокса

Прошивка ESP32 и собственная плата управления освещением, вентиляцией, поливом и обогревом. Температура и влажность измеряются внешним SHT4x; настройки доступны через веб-интерфейс, расписания используют RTC, журнал сохраняется на microSD.

## Структура репозитория

| Папка | Содержимое |
| --- | --- |
| [software/](software/README.md) | Прошивка Arduino для ESP32, веб-интерфейс и инструкция по сборке |
| [hardware/](hardware/README.md) | Проекты KiCad 10, BOM, модели деталей, корпус и файлы изготовления |
| [tests/](tests/) | Автоматические тесты веб-интерфейса |
| [vps-docs/](vps-docs/README.md) | Инструкция по работе с удалённой KiCad-станцией |

## Аппаратная часть

- [PCB_V1](hardware/PCB_V1/README.md) — основной проект платы: вход 24 В, четыре слоя, размер до 100×100 мм.
- [cheap-version](hardware/cheap-version/README.md) — вариант платы с использованием имеющихся компонентов. Файлы изготовления и состояние проверок описаны в его [FAB.md](hardware/cheap-version/FAB.md).
- [Корпус](hardware/enclosure/README.md) — параметрическая модель для 3D-печати; перед использованием сверяйте её с выбранной версией платы.

## Начало работы

Для прошивки откройте `software/software.ino`; зависимости, загрузка веб-интерфейса и проверки описаны в [software/README.md](software/README.md).

Для платы откройте нужный проект KiCad: `hardware/PCB_V1/PCB_V1.kicad_pro` или `hardware/cheap-version/cheap-version.kicad_pro`. Инструкции по проверкам и изготовлению находятся в документации соответствующего проекта.

Правила работы с репозиторием — [AGENTS.md](AGENTS.md).
