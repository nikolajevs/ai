# Claude instructions

Read and follow `AGENTS.md` before making repository changes.

For VPS architecture, commands, access, operations and troubleshooting, also read:

`vps-docs/README.md`

Use a dedicated task branch and never make development commits directly to `main`.
In an isolated cloud task, use the existing checkout; create a worktree only when requested.
The former KiCad VPS workstation and its checkouts were removed; do not assume they are available.
