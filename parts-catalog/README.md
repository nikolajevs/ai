# Каталог деталей PCB_EU

Локальная программа: цены и остатки из четырёх магазинов (Salvats, Electrobase, Semikom, Lemona) лежат в базе SQLite на вашем компьютере. По ней работают поиск, проверка BOM платы PCB_EU и подбор аналогов. Программа только читает страницы магазинов и файлы `hardware/PCB_EU`; она ничего не покупает и не меняет ни плату, ни BOM.

Стек: Python 3.10+, FastAPI, Jinja2, HTMX (лежит в `partscat/static/`, интернет для страницы не нужен), SQLite, requests, BeautifulSoup.

## Запуск на Windows

1. Распакуйте архив и дважды щёлкните `start.bat`. Он ищет Python в `C:\PST\py\python.exe`, потом в `PATH`; при первом запуске сам доустановит библиотеки из `requirements.txt` (нужен интернет, 1–2 минуты). Страница откроется на http://127.0.0.1:8086; окно с программой не закрывайте, остановка — `Ctrl+C`.
2. Проверьте связь с магазинами: кнопка «Проверить связь» на странице «Сбор» или `start.bat doctor` в консоли. На каждый магазин по три запроса с паузами: `robots.txt`, одна страница товара, один поиск (если магазин его разрешает); около минуты, в базу ничего не пишется. Результат построчно: `[ ok ]`, `[ !! ]` или `[FAIL]` и причина (блокировка, бан, изменилась вёрстка, нет доступа в сеть). Консольный `doctor` ещё проверяет установку, базу и BOM, ключ `--offline` ограничивает его только этим.
3. Первый сбор: страница «Сбор» → «Обновить позиции BOM». Читается около 80 страниц деталей платы (на 2026-10-23: 61 Salvats и 18 Electrobase); между запросами паузы 1,5–2,5 с, всего около 3–5 минут. Ход виден на странице, кнопка «Остановить» безопасна: прочитанное уже в базе.
4. Страница «BOM» покажет, что изменилось с момента записи BOM: цены, остатки, артикулы.

Без архива, из репозитория: `cd parts-catalog`, `python -m pip install -r requirements.txt`, `python run.py`. BOM тогда берётся из `../hardware/PCB_EU`.

Порт можно сменить: `start.bat serve --port 8090` или переменная `PARTSCAT_PORT`.

Если рядом лежит `data\catalog.db` первой версии каталога (таблица `components`), программа не читает её, а переименовывает в `catalog.v1-backup.db` и начинает чистую базу.

## Что внутри

### Поиск

Строка понимает слова и параметры вперемешку:

| Запрос | Что ищется |
| --- | --- |
| `FDB5800` | артикул (точное совпадение выше, части названия ниже) |
| `n-mosfet 60V 80A D2PAK` | N-канальные MOSFET, Vds не меньше 60 В, Id не меньше 80 А, корпус TO-263 |
| `n-mosfet 100V <10mΩ TO-220 logic` | то же, Rds(on) не больше 10 мОм, logic-level |
| `schottky 100V 5A SMC` | диоды Шоттки |
| `100nF 50V 0805` | конденсаторы 100 нФ в корпусе 0805 |
| `10k 0603 1%` | слова ищутся по названию, артикулу, бренду и разделу |

`60V` означает «не меньше 60 В», `<10mΩ` — «не больше 10 мОм», `>=5A` и `≥5A` тоже понимаются. Под строкой показано, как запрос понят. Предложения одного артикула из разных магазинов собраны в одну карточку; поле «Нужно штук» считает цену с учётом упаковок, ступеней цены и минимального заказа; самое дешёвое подсвечено.

Если в базе чего-то нет, кнопка «Спросить магазины» запускает поиск в Salvats и Semikom и читает карточки без артикула.

### Проверка BOM

BOM читается из `BOM_allocated.csv`, `BOM_allocated.json` и `design.json` (значения и посадочные места позиций). Для каждой строки сравнивается последнее прочитанное предложение магазина:

- цена (отклонение от 5 % и 2 центов — «проверить»), упаковка, артикул в магазине;
- остаток против количества к покупке (остаток позиции, продаваемой упаковкой, пересчитывается из упаковок в штуки), «нет в наличии», «под заказ»;
- возраст данных (старше трёх дней — «проверить»);
- есть ли тот же артикул дешевле в другом магазине;
- для резисторов, конденсаторов, MOSFET и биполярных транзисторов: корпус, номинал, допуск, напряжение, полярность из названия в магазине против схемы.

Уровни: «в порядке», «проверить», «проблема», «нет данных» (страница ещё не читалась). Итог показывает сумму по BOM, сумму по базе и доставку из `review/BOM_summary.json`. Результат выгружается в CSV (`Скачать CSV`, `python run.py bom --csv файл.csv`).

### Аналоги

Для строки BOM или для любой детали в базе (страница детали → «Аналоги») подбираются замены того же типа с вердиктом:

- «можно ставить» — всё, что известно, не хуже оригинала;
- «проверить» — часть параметров магазин не указал или они хуже;
- «другой корпус» — электрически подходит, но нужна другая посадка;
- «не подходит» — скрыто, показывается по ссылке.

У каждого параметра свой знак (лучше, нормально, хуже, неизвестно). Rds(on) сравнивается только когда оба значения взяты из одного источника: название и список свойств в магазине иногда дают разные числа, тогда параметр помечается «неизвестно». Цоколёвку, нагрев и графики программа не проверяет, это по даташиту. «Дочитать карточки кандидатов» открывает страницы магазинов и добирает недостающие параметры.

### Сбор данных

| Действие на странице «Сбор» | Что делает |
| --- | --- |
| Обновить позиции BOM | страницы всех строк BOM и список наблюдения |
| Только список наблюдения | то, что вы отметили кнопкой «В наблюдение» или добавили адресом |
| Узнать артикулы | читает карточки без известного артикула (Electrobase и Semikom не дают его в списках) |
| Спросить магазины | поиск Salvats и Semikom по вашему запросу |
| Обойти разделы | листинги разделов магазина страница за страницей; так читается Electrobase |
| Прочитать страницы по адресам | адреса товаров по одному в строке; так добавляется Lemona |
| Проверить связь | по три запроса на магазин (`robots.txt`, страница товара, поиск), ничего не сохраняет |

Как читается каждый магазин:

| Магазин | Способ |
| --- | --- |
| Salvats | HTML: поиск и карточки товаров; артикул — поле «Artikuls» |
| Electrobase | `robots.txt` запрещает поиск, поэтому разделы каталога постранично и страницы товаров |
| Semikom | поиск `/<запрос>.gs`, страницы товаров `.p`, группы `.g`; в списках артикула нет |
| Lemona | GraphQL магазина по адресу страницы; поиск у магазина идёт через сторонний сервис и не используется |

Правила вежливости, они не отключаются: честный `User-Agent`, `robots.txt` соблюдается (запрещённое не запрашивается), пауза между запросами к одному магазину (Semikom не меньше 4,6 с, Electrobase 2,5 с, Salvats и Lemona 1,5 с), после ответа о бане магазин не опрашивается 10 минут, четыре сетевые ошибки подряд отключают магазин до конца запуска. Причина пропуска показывается на странице, не прячется. Листинги кэшируются на диске на 20 часов (остановленный обход продолжается без повторных запросов); цены деталей BOM и наблюдения каждый раз читаются заново.

### Командная строка

```
python run.py                        # страница (то же, что serve)
python run.py doctor [--offline] [--shop salvats]
python run.py crawl bom              # страницы деталей BOM и наблюдение
python run.py crawl urls АДРЕС ...   # прочитать страницы и добавить в наблюдение
python run.py crawl search FDB5800   # спросить магазины с поиском
python run.py crawl sweep salvats --match tranzistori --pages 40
python run.py crawl enrich --limit 30
python run.py bom [--all] [--level warn] [--analogs] [--csv bom_check.csv]
python run.py search n-mosfet 60V 80A D2PAK [--shop salvats] [--in-stock] [--qty 5]
python run.py analogs FDB5800 [--all]
python run.py export offers.csv      # все предложения из базы
```

Общие ключи: `--data ПАПКА` (база и кэш; по умолчанию `data/` рядом с `run.py` или `PARTSCAT_DATA`), `--bom ПАПКА` (с `BOM_allocated.csv` и `design.json`; иначе `PARTSCAT_BOM_DIR`, папка `bom/` рядом с `run.py`, `../hardware/PCB_EU`).

## BOM в архиве

В архиве папка `bom/` — снимок файлов платы на день сборки архива: `BOM_allocated.csv`, `BOM_allocated.json`, `design.json` и `BOM_summary.json` (в репозитории он лежит в `review/`). Когда BOM в репозитории изменится, замените эти файлы или укажите свежую папку `hardware/PCB_EU` в переменной `PARTSCAT_BOM_DIR`. Свежий архив собирает `python parts-catalog/tools/pack_windows.py` из корня репозитория.

## Что проверено, что нет

- Разборщики всех четырёх магазинов проверены на сохранённых настоящих страницах (`tests/fixtures/`, прочитаны 2026-10-23). Автотесты проходят без сети на Python 3.10, 3.12 и 3.13, в том числе с самыми старыми версиями библиотек из `requirements.txt`. На самой Windows программа не запускалась: `start.bat` проверен только чтением, пути собираются через `pathlib`, файлы читаются и пишутся с явной кодировкой UTF-8.
- Живой прогон по магазинам с компьютера разработки не делался: это ваш первый запуск. Начните с «Проверить связь». Если какая-то строка `[FAIL]` или `[ !! ]`, пришлите её текст и текст ошибок со страницы «Сбор».
- Допущения, которые живой прогон может опровергнуть: у позиций Salvats, продаваемых упаковкой, остаток считается в упаковках; листание Semikom (`?p=N`, следующая страница есть, если на этой 30 карточек) выведено из сохранённых страниц; `robots.txt` прочитан у Electrobase (отсюда обход разделов вместо поиска); у Salvats, Semikom и Lemona программа читает его сама при первом запросе и выполняет, а `doctor` показывает, что он разрешает.
- Вердикт аналога подсказка, а не разрешение на замену; решение по даташиту.

## Безопасность

Сервер слушает только `127.0.0.1`; запросы с чужим заголовком `Host` отклоняются, как и POST с чужого `Origin`. Ссылки на магазины открываются только по `http`/`https`, текст страниц магазинов экранируется. Паролей и ключей программа не хранит и не требует. База и кэш лежат в `data/` и в репозиторий не попадают.

## Для разработчика

```
python -m pip install -r requirements-dev.txt
python -m pytest                     # тесты, без сети
```

```
partscat/
  shops/      по модулю на магазин: разбор страниц функциями без сети + запросы через Client
  http.py     вежливый клиент: robots.txt, паузы, кэш, понятные ошибки
  db.py       SQLite: предложения, история цен, запуски сбора, список наблюдения
  params.py   параметры из названий и свойств (Vds, Id, Rds(on), корпус, номинал ...)
  search.py   разбор запроса, ранжирование, группировка по артикулу
  pricing.py  цена на N штук: упаковки, ступени, минимальный заказ, остаток
  bom.py      чтение BOM и проверка строк
  analogs.py  вердикты и сравнение параметров
  crawler.py  планы сбора, ход выполнения, остановка
  web.py      страницы (FastAPI + HTMX), templates/, static/
  cli.py      командная строка; doctor.py — проверка установки и связи
tools/pack_windows.py    архив для Windows с пустой базой и снимком BOM
```

Новый магазин — это класс в `partscat/shops/` с методами `product`, при необходимости `search` и `listing`, строчка в `shops/__init__.py` и сохранённые страницы в `tests/fixtures/`. Разбор пишется функциями от HTML или JSON, чтобы тестироваться без сети.
