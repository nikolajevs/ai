# Общая комната GrowBox

Локальный чат для пользователя, Codex и Claude Code. Использует установленные CLI и их штатную авторизацию. Python 3.10+, сторонние пакеты не нужны.

На Windows откройте **`start.cmd`**: он запустит сервер в фоне и откроет браузер. Повторный запуск открывает уже работающую комнату. Для запуска сервера вручную:

```powershell
python tools/team-chat/server.py
```

Откройте `tools/team-chat/.local/room.url`. Сервер слушает только `127.0.0.1:8767`; адрес содержит ключ доступа. История хранится в `.local/history.json`, исключённой из Git. Для другого порта: `--port 8768`.

- `@codex`, `@claude`, `@оба` в начале сообщения выбирают адресата; также есть список под полем ввода.
- «Обоим»: Codex отвечает первым, Claude получает и его ответ. Следующее обращение к Codex включает ответ Claude. Самостоятельной бесконечной переписки нет.
- Полная история комнаты и текущие `pcb/PCB_V1/README.md` + `DESIGN.md` передаются выбранному поставщику модели. Чужие открытые чаты не читаются и не импортируются.
- Это режим обсуждения: Claude запускается без инструментов; Codex — в read-only sandbox с инструкцией не вызывать инструменты. Изменять проект из комнаты нельзя. Существующие сессии в приложениях продолжают работать отдельно.
- Используются настройки модели CLI без принудительного выбора модели. Запросы расходуют доступные лимиты учётной записи; способ оплаты зависит от настроенной авторизации CLI.
- Каждый ответ — отдельный процесс с общей историей. Ответ появляется целиком; тайм-аут 5 минут. При превышении лимита контекста ошибка показывается в комнате; история не обрезается молча.

## Подключение

Codex: `codex login status`, при необходимости `codex login`.

Claude: `claude auth status`, при необходимости `claude auth login --claudeai`. Авторизация в приложении Claude не обязательно доступна отдельному CLI. Вход выполните самостоятельно, не копируйте токены в файлы проекта.

Сервер ищет CLI в PATH, затем в обычных каталогах Windows, включая Claude из Microsoft Store. Можно задать абсолютные пути через `TEAM_CHAT_CODEX` и `TEAM_CHAT_CLAUDE`. Если CLI найден внутри приложения, команда входа запускается по этому полному пути.

Проверка без обращений к моделям: `python -m unittest discover -s tools/team-chat -p "test_*.py"`.

Интерфейсы: [Codex exec](https://developers.openai.com/codex/noninteractive), [Claude Code print mode](https://code.claude.com/docs/en/headless).
