# PCB_V1 — файлы для производства на JLCPCB, ревизия 0.22

01.10.2026, ветка `pcb-fab`. Разведённая плата ([ROUTING.md](ROUTING.md)) проверена по технологическим нормам JLCPCB, экспортирована в Gerber и сверловку; архив для загрузки лежит в [../fab/PCB_V1_v22_jlcpcb.zip](../fab/PCB_V1_v22_jlcpcb.zip).

**Итог: нарушений норм JLCPCB нет (0 FAIL), 2 предупреждения без последствий.** Единственное, что пришлось изменить в плате, — ширина 494 линий шёлкографии (0,12 → 0,15 мм, минимум JLCPCB). Онлайн-проверку JLCPCB на их сайте я не запускал: для этого нужно загрузить файлы на чужой сервис, и решать это вам (раздел 5).

## 3. Проверка технологичности

`check_fab.py` сравнивает плату с нормами JLCPCB для многослойных плат с наружной медью 1 oz. Нормы прочитаны 01.10.2026 на [странице возможностей JLCPCB](https://jlcpcb.com/capabilities/pcb-capabilities); это моя проверка по опубликованным числам, а не проверка самого JLCPCB. Запускается из `check_all.py`, полный отчёт — [../review/DFM_JLCPCB_v22.txt](../review/DFM_JLCPCB_v22.txt).

| Параметр | Норма JLCPCB | В плате | |
|---|---|---|---|
| Размер платы | ≤ 663 × 593 мм; ценовая категория 100 × 100 | 100,00 × 100,00 мм | ✓ |
| Толщина | 1,6 мм ±10 % | 1,606 мм | ✓ |
| Ширина дорожки / зазор | 0,09 / 0,09 мм | дорожки ≥0,25 мм, правило проекта 0,2 / 0,15 мм (классы цепей ≥0,2) | ✓ |
| Переходные: отверстие / диаметр | 0,15 / 0,25 мм, диаметр на 0,1 мм больше отверстия | 0,3 / 0,65 мм (188), 0,4 / 0,8 мм (104) | ✓ |
| Поясок переходного | ≥0,15 мм, рекомендуется 0,20 | 0,175 мм (0,3/0,65) и 0,20 мм (0,4/0,8) | ✓ / предупреждение |
| Поясок металлизированных отверстий | ≥0,15 мм, рекомендуется 0,20 | ≥0,20 мм (J901) | ✓ |

**Исправлено.** 494 линии шёлкографии (контуры посадочных мест из стандартных библиотек KiCad) были шириной 0,12 мм, меньше минимума JLCPCB. Выставлена ширина 0,15 мм: `python check_fab.py PCB_V1/PCB_V1.kicad_pcb --fix-silk`. Больше в плате ничего не менялось, DRC остался 0/0. Если посадочные места позже обновятся из библиотеки, проверка снова это покажет, и команду можно повторить.

**Предупреждения (не блокируют заказ):**
1. *Поясок переходных 0,175 мм* при рекомендуемых 0,20 мм (абсолютный минимум 0,15 мм). Это выбор проекта 0,3/0,65 мм; меньше рекомендации, но больше минимума, а выбранный вариант заказа «0,3/0,4 мм» соблюдён. Более широкие переходные 0,3/0,7 мм потребовали бы повторного прохода всей трассировки.
2. *33 пары одноимённых дорожек ближе 0,25 мм без касания* (6 из них ближе 0,09 мм и вытравятся как единый кусок меди, остальные 27 — узкие щели внутри одной цепи). Это следы автотрассировщика; замыканий нет, цепь одна и та же. JLCPCB иногда отмечает такие места в своём отчёте, на качество плат это не влияет.

## 4. Как пересоздать и проверить

Из папки `pcb`, интерпретатор — Python из KiCad (нужен `kicad-cli` KiCad 10):

```text
python export_fab.py            # экспорт, чтение файлов обратно, сборка fab/PCB_V1_v22_jlcpcb.zip
python export_fab.py --check    # сравнить заново собранный архив с лежащим в fab/
python check_fab.py PCB_V1/PCB_V1.kicad_pcb    # проверка платы по нормам JLCPCB
```

`export_fab.py` читает экспортированные файлы и сверяет их с платой: назначение каждого слоя (X2), контур 100 × 100 мм, самая узкая нарисованная дорожка (меди 0,25 мм, шёлка 0,15 мм), число отверстий каждого диаметра в обоих файлах сверловки. После любого изменения платы архив нужно собрать заново.

## 5. Что осталось

1. **Онлайн-проверка JLCPCB.** Загрузка `PCB_V1_v22_jlcpcb.zip` на странице заказа запускает их автоматический DFM и показывает Gerber в их просмотрщике. Это единственная проверка на их оборудовании. Я её не запускал: файлы пришлось бы отправить на сторонний сайт. Если разрешите, могу загрузить архив на страницу расчёта без входа в аккаунт и разобрать отчёт, но чертёж платы станет доступен сервису JLCPCB.
2. **Gerber в стороннем просмотрщике** (например, gerbv или GerbView): проверка независима от KiCad. Я такую программу не ставил.
3. **Сборка.** Первые платы собираются вручную, файлы для SMT-сборки JLCPCB (BOM, CPL) не готовились; состав — `BOM_schematic.csv`, оценка — [JLC_assembly_v22.txt](../review/JLC_assembly_v22.txt).
4. **Прежние вопросы:** осмотр платы в KiCad, тонкое место HEATER_DRAIN (3,1 мм при 3,02 мм, [ROUTING.md](ROUTING.md) раздел 6), механика (образцы разъёмов, распечатка 1:1, корпус) — на вас.
