# PCB_V1 — файлы для производства на JLCPCB, ревизия 0.22

01.10.2026, ветки `pcb-fab` и `pcb-dfm-fixes`. Разведённая плата ([ROUTING.md](ROUTING.md)) экспортирована в Gerber и сверловку; архив для загрузки — [../fab/PCB_V1_v22_jlcpcb.zip](../fab/PCB_V1_v22_jlcpcb.zip). Первый архив был проверен автоматическим анализатором JLCPCB (JLCDFM, отчёт прислал пользователь): он нашёл замечания по шёлкографии, маске и переходным отверстиям. Они устранены в плате и в архиве (раздел 3); **повторная загрузка архива в JLCDFM покажет, что осталось**.

## 3. Отчёт JLCDFM и что с ним сделано

JLCDFM ([dfm.jlcdfm.com](https://dfm.jlcdfm.com)) проверил `PCB_V1_v22_jlcpcb.zip` первой версии (4 слоя, 10 × 10 см, только PCB DFM). В отчёте нет координат — по одной иллюстрации на правило, — поэтому места найдены по картинкам и значениям, и каждое подтверждено своей геометрией.

| Правило JLCDFM | Результат первого отчёта | Причина и что сделано |
|---|---|---|
| Ширина и зазор дорожек, острые углы, оборванные концы, дорожка/площадка до края, расстояние между площадками, зазор сквозного отверстия до дорожки, поясок, расстояние между отверстиями, пазы, переходное в площадке, перемычка маски, многосегментные отверстия маски | замечаний нет (дорожки 0,25 мм и зазор 0,2 мм — Good; зазор отверстия до дорожки 0,38 мм; поясок 0,17 мм) | — |
| **Via to pad** | 0,07 мм, **Danger 1** | GND-переходное между C716.2 и C717.2 в зазоре 0,8 мм: до обеих площадок 0,075 мм. **Удалено** (у этих конденсаторов остаются другие переходные) |
| *Мои проверки того же рода* | — | Ещё три GND-переходных наползали на соседние GND-площадки (R210.2, C906.2, U601.4). Привязка земли теперь не допускает касания соседних площадок; эти три переделаны (C602.2 — вручную, одно свободное место) |
| **Solder mask opening exposing trace** | 0,05 мм, **Danger 1, Warning 1** | Дорожка той же цепи идёт мимо площадки без касания на 0,04–0,07 мм, отверстие маски её открывает. Пять мест: у C712.1, R513.1, R306.2 и C106.1 вершины дорожек сдвинуты или сегменты объединены, у R210.2 причиной была перекрывающая привязка земли C601.2, она переделана |
| **THT to SMD** | 0,41 мм, **Danger 2, Warning 8**, Good 42 | Круглая площадка держателя батарейки BT301.2 и SMD-площадка F301.1: 0,41 мм. **F301 сдвинут на 0,1 мм** (теперь 0,55 мм). Остальные 8 предупреждений я по отчёту сопоставить не смог (порог неизвестен) |
| **Silkscreen to pad** | 0 мм, **Danger 27, Warning 2**, Good 21 | Шёлк касался площадок (вычитание маски обрезало его по краю площадки). Шёлк обрезан на 0,15 мм от меди площадок (46 фигур) |
| **Silkscreen to hole** | 0 мм, **Danger 52** | Контуры шёлка проходили над отверстиями и переходными. Шёлк обрезан на 0,15 мм от каждого отверстия и переходного; 7 надписей сдвинуты на 0,2–2 мм (PTC 24V на 1,0, PUMP 24V на 2,0 мм, остальные на 0,2 мм) |
| **Silkscreen line width** | 0,15 мм, **Warning 59** | Штрих 0,15 мм — на самом минимуме JLCPCB. Все линии, дуги, контуры заливки и текст — **0,2 мм** (485 + 29 штрихов) |
| **Negative soldermask expansion** | 0,04 мм, **Warning 50** | **Не менялось.** Отверстия маски в файлах побайтно совпадают с площадками (те же апертуры), JLCPCB принимает 1:1; расширение больше 0 сузило бы перемычки маски. Вероятно, артефакт анализа скруглённых площадок |

Изменения в плате: удалено 1 переходное, пересоздано 3, исправлено 4 угла дорожек, сдвинут F301, пересчитан шёлк; DRC 0/0, `check_all.py` проходит, связность не менялась. Файл проекта: серьёзность сообщения DRC `lib_footprint_mismatch` («посадочное место отличается от библиотеки») поставлена в `ignore`, потому что шёлк 29 посадочных мест из стандартных библиотек теперь отличается от библиотечного намеренно. Правки сделаны скриптами `fab_touchups.py` (точечные правки по координатам этой разводки) и `check_fab.py --fix-silk` (шёлк); оба описаны в начале файлов.

## 4. Проверка по опубликованным нормам JLCPCB

`check_fab.py` сравнивает плату с нормами JLCPCB для многослойных плат с наружной медью 1 oz (нормы прочитаны 01.10.2026 на [странице возможностей](https://jlcpcb.com/capabilities/pcb-capabilities)) и с категориями JLCDFM, которые нормы прямо не называют (шёлк у площадок и отверстий, переходное у площадки, дорожка у площадки, выводная площадка у SMD). Запускается из `check_all.py`; полный отчёт — [../review/DFM_JLCPCB_v22.txt](../review/DFM_JLCPCB_v22.txt). **Итог: 0 FAIL, 2 предупреждения.**

|---|---|---|---|
| Размер платы | ≤ 663 × 593 мм; ценовая категория 100 × 100 | 100,00 × 100,00 мм | ✓ |
| Толщина | 1,6 мм ±10 % | 1,606 мм | ✓ |
| Ширина дорожки / зазор | 0,09 / 0,09 мм | дорожки ≥0,25 мм, правило проекта 0,2 / 0,15 мм | ✓ |
| Переходные: отверстие / диаметр | 0,15 / 0,25 мм | 0,3 / 0,65 мм (187), 0,4 / 0,8 мм (104) | ✓ |
| Поясок переходного | ≥0,15 мм, рекомендуется 0,20 | 0,175 мм и 0,20 мм | ✓ / предупреждение |
| Поясок металлизированных отверстий | ≥0,15 мм, рекомендуется 0,20 | ≥0,20 мм | ✓ |
| Металлизированные / неметаллизированные отверстия | ≥0,5 мм | ≥0,9 / 1,0 мм | ✓ |
| Пазы | ширина ≥0,35 мм, длина ≥2× ширины | 2 паза 0,9 × 2,0 мм (XT60) | ✓ |
| Отверстие — отверстие | переходные 0,2 мм; выводы 0,45 мм | выдержано | ✓ |
| Край отверстия — чужая медь | ≥0,28 мм (рекомендуется 0,35) | ≥0,49 мм | ✓ |

| Переходное у площадки | не касается и не ближе 0,1 мм (тепловые площадки U902 и U201 — исключение) | выдержано | ✓ |
| Дорожка мимо площадки без касания | ≥0,09 мм | выдержано | ✓ |
| Выводная площадка — SMD-площадка | рекомендация JLCDFM ≥0,5 мм | выдержано (было 0,41 мм) | ✓ |

| Медь — край платы | ≥0,2 мм | 0,5 мм | ✓ |

**Предупреждения (не блокируют заказ):**
1. *Поясок переходных 0,175 мм* при рекомендуемых 0,20 мм (минимум 0,15 мм). В JLCDFM поясок 0,17 мм получил оценку Good. Более широкие переходные потребовали бы повторного прохода всей трассировки.
2. *31 пара одноимённых дорожек ближе 0,25 мм без касания* (5 из них ближе 0,09 мм и вытравятся как единый кусок меди, остальные — узкие щели внутри одной цепи). JLCDFM их не отметил; замыканий нет.

## 5. Как пересоздать и проверить

Из папки `pcb`, интерпретатор — Python из KiCad (нужен `kicad-cli` KiCad 10):

```text
python export_fab.py            # экспорт, чтение файлов обратно, сборка fab/PCB_V1_v22_jlcpcb.zip
python export_fab.py --check    # сравнить заново собранный архив с лежащим в fab/
python check_fab.py PCB_V1/PCB_V1.kicad_pcb              # проверка платы
python check_fab.py PCB_V1/PCB_V1.kicad_pcb --fix-silk   # шёлк: штрих 0,2 мм, обрезка у площадок и отверстий, сдвиг надписей
```

`export_fab.py` читает экспортированные файлы и сверяет их с платой: назначение каждого слоя (X2), контур 100 × 100 мм, самый узкий штрих (медь 0,25 мм, шёлк 0,2 мм), число отверстий каждого диаметра в обоих файлах сверловки. После любого изменения платы архив нужно собрать заново.

## 6. Что осталось

1. **Повторная загрузка архива в JLCDFM** (вы, как в первый раз) — чтобы увидеть, какие замечания остались. Ожидаю, что шёлк и переходное станут чистыми; под вопросом «Negative soldermask expansion» (50 предупреждений, файлы не менялись) и 8 предупреждений «THT to SMD».
2. **Gerber в стороннем просмотрщике** (например, gerbv или GerbView): независимая от KiCad проверка. Я такую программу не ставил.
3. **Сборка.** Первые платы собираются вручную, файлы для SMT-сборки JLCPCB (BOM, CPL) не готовились; состав — `BOM_schematic.csv`, оценка — [JLC_assembly_v22.txt](../review/JLC_assembly_v22.txt).
4. **Прежние вопросы:** осмотр платы в KiCad, тонкое место HEATER_DRAIN (3,1 мм при 3,02 мм, [ROUTING.md](ROUTING.md) раздел 6), механика (образцы разъёмов, распечатка 1:1, корпус) — на вас.
